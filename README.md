# Pygram 🕊️ 

**Pygram** — это децентрализованный мессенджер, работающий поверх обычной сетевой папки (SMB). Без выделенного сервера, без облаков и без баз данных на стороне провайдера. Все данные (сообщения, ключи, профили) хранятся в файловой шаре, а клиент написан на Python + PySide6.

## 🚀 Основные возможности

*   **Серверless архитектура:** Работает в любой локальной сети с SMB-папкой (например, в колледже или офисе).
*   **Сквозное шифрование:** AES-256-GCM, RSA-3072. Логины, пароли и сообщения никогда не хранятся в открытом виде.
*   **Группы и личные сообщения:** Гибридное шифрование для DM и надежное управление ключами для групп.
*   **Мультиаккаунт:** До 3 активных аккаунтов одновременно.
*   **Устойчивость к сетевым сбоям:** Специальная логика ретраев для работы с SMB (защита от `WinError 5` при блокировке файлов антивирусом).
*   **Богатый UI:** Темная тема, кастомизация цветов и шрифтов, реакции на сообщения, отправка файлов и скриншотов (Ctrl+V).
*   **Панель администратора:** Гранулярные права (просмотр всех чатов, управление админами), защищенные цифровыми подписями.

## 🛡️ Безопасность и компромиссы

Проект использует современные криптографические примитивы:
*   **Пароли:** Argon2id (time=3, memory=64MB, parallelism=4).
*   **Приватные ключи:** Шифруются через Argon2id + AES-GCM (AAD привязка к fingerprint).
*   **Сообщения:** AES-256-GCM + RSA-OAEP (гибрид) и подписи RSA-PSS.
*   **Логины:** Хранятся в шаре только в виде SHA-256 хеша.

**Осознанные компромиссы (by design):**
*   Приватный ключ хранится в шаре (зашифрован). Утечка шары позволяет провести офлайн-брутфорс (медленный, но возможный).
*   Нет Forward Secrecy (компрометация ключа = чтение всей истории).
*   Администраторы с соответствующими правами могут читать все чаты (модерация).
*   Использование DPAPI отклонено в пользу мобильности (вход с любого ПК).

## 📦 Установка и запуск (для пользователей Windows)

Для обычных пользователей не нужно устанавливать Python. Готовый `.exe` можно скачать в разделе **Releases**.

1. Скачайте архив `Pygram_v0.2.3.zip` из раздела **Releases**.
2. Распакуйте архив в любую удобную папку (например, на Рабочий стол).
3. Запустите `Pygram.exe`.
4. При первом запуске выберите папку вашей сетевой шары (SMB).
5. Зарегистрируйтесь (первый зарегистрировавшийся становится Супер-админом).

*Примечание: при первом запуске `.exe` может занять 5-10 секунд (распаковка ресурсов во временную папку).*

## 🛠 Для разработчиков

### Требования
*   Python 3.10+ (Рекомендуется 3.12)
*   Windows 10/11
*   Доступ к SMB-папке (с правами на чтение/запись)

### Запуск из исходников
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/dkbunnyx/Pygram.git
cd Pygram

# 2. Создайте виртуальное окружение и активируйте его
python -m venv .venv
.venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. (Опционально) Настройте .env, если не хотите выбирать папку каждый раз
copy .env.example .env
# Откройте .env и укажите SHARED_FOLDER=путь_к_вашей_шаре

# 5. Запустите клиент
python main.py
```
Сборка .exe (PyInstaller)
Проект содержит настроенный Pygram.spec для сборки в один исполняемый файл.
pip install pyinstaller
pyinstaller Pygram.spec
Готовый .exe появится в папке dist/.
