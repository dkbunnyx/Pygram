# Pygram 🕊️

**Pygram** — децентрализованный мессенджер, работающий поверх обычной сетевой папки (SMB). Без выделенного сервера, облачных сервисов и баз данных на стороне провайдера.

Все общие данные (сообщения, ключи, профили и вложения) хранятся в сетевой папке, а клиентское приложение написано на Python с использованием PySide6.

Проект находится в стадии активной разработки (**Beta 0.2.5**).

---

## 🚀 Основные возможности

- **Serverless-архитектура:** работа через общую SMB-папку в локальной сети без необходимости разворачивать отдельный сервер.
- **Сквозное шифрование:** AES-256-GCM, RSA-3072 и гибридная схема шифрования сообщений.
- **Личные и групповые чаты:** обмен сообщениями и файлами с использованием криптографической защиты.
- **Мультиаккаунт:** поддержка до 3 активных аккаунтов.
- **Управление пользователями:** профили, статусы, список участников и административная панель.
- **Гибкая система прав:** разграничение полномочий супер-администратора, администраторов и обычных пользователей.
- **Управление сообщениями:** удаление собственных и чужих сообщений с учётом выданных разрешений.
- **Вложения:** отправка файлов, изображений и скриншотов через Ctrl+V.
- **Реакции:** возможность реагировать на сообщения.
- **Настройка интерфейса:** темы оформления, цвета и шрифты.
- **Устойчивость к сетевым сбоям:** повторные попытки операций с файлами и обработка временной блокировки файлов.

## 🛡️ Безопасность

Безопасность является одним из основных направлений разработки Pygram.

### Криптография

- **Пароли:** хеширование с использованием Argon2id.
- **Приватные ключи:** шифрование с помощью Argon2id и AES-GCM с привязкой AAD к fingerprint.
- **Сообщения:** AES-256-GCM, RSA-OAEP и цифровые подписи RSA-PSS.
- **Публичные ключи:** проверка соответствия fingerprint сохранённому публичному ключу.
- **Идентификация:** логины в общей папке хранятся в виде SHA-256-хешей.

### Цепочка доверия

- Локальное закрепление fingerprint первого супер-администратора.
- Проверка цепочки доверия при работе с административным списком.
- Самоподписанный корневой сертификат супер-администратора.
- Проверка цифровых подписей административных записей.
- Подтверждение fingerprint корневого администратора при первом подключении с нового компьютера.

### Защита входа

- Локальное ограничение количества неудачных попыток входа.
- Увеличение задержки между попытками: 30, 60 и 180 секунд.
- Отдельная обработка ошибок неверного пароля.

### Административные права

- Разделение полномочий супер-администратора и обычных администраторов.
- Возможность выдавать обычным пользователям разрешение на удаление чужих сообщений.
- Отдельное разрешение на выдачу другим пользователям права удаления.
- Проверка полномочий перед выполнением административных операций.

### Работа с файлами

- Атомарная запись критически важных данных.
- Повторные попытки атомарной замены файлов при временных блокировках.
- Синхронизация временных файлов через fsync при потоковом шифровании и расшифровке.
- Ограничения размера административного файла и количества записей.

### Известные ограничения

- Приватный ключ пользователя хранится в общей папке в зашифрованном виде. При получении доступа к файлу остаётся возможность офлайн-перебора пароля.
- В текущей архитектуре отсутствует Forward Secrecy: компрометация ключа может привести к раскрытию соответствующей истории сообщений.
- Администраторы с необходимыми полномочиями могут получать доступ к данным чатов.
- Локальное закрепление root fingerprint не заменяет полноценную инфраструктуру управления ключами и сертификатами.

## 📦 Установка и запуск (Windows)

Для обычного использования Python устанавливать не требуется.

### Скачать готовое приложение

1. Перейдите в раздел [GitHub Releases](https://github.com/dkbunnyx/Pygram/releases).
2. Скачайте файл `Pygram.exe` из нужного релиза.
3. Запустите скачанный файл.
4. При первом запуске выберите общую сетевую папку SMB.
5. Создайте учётную запись.

Первый зарегистрировавшийся пользователь становится супер-администратором.

При первом запуске с нового компьютера может потребоваться подтверждение fingerprint корневого супер-администратора.

**Важно:** для работы приложения необходима общая папка с доступом на чтение и запись.

### Хранение локальных данных

В режиме разработки конфигурация хранится в корне проекта.

В собранной версии приложения локальные данные располагаются в:

`%APPDATA%\Pygram`

Там находятся локальная конфигурация, логи и резервные копии.

## 🛠 Для разработчиков

### Требования

- Windows 10/11.
- Python 3.10 или новее.
- Доступ к SMB-папке с правами чтения и записи.

### Запуск из исходников

Клонируйте репозиторий:

```powershell
git clone https://github.com/dkbunnyx/Pygram.git
cd Pygram
```

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

При необходимости создайте `.env` на основе примера:

```powershell
Copy-Item .env.example .env
```

Укажите в `.env` путь к общей папке:

```env
SHARED_FOLDER=путь_к_вашей_сетевой_папке
```

Запустите приложение:

```powershell
python main.py
```

### Сборка EXE

Для сборки используется PyInstaller и конфигурация `Pygram.spec`.

Установите PyInstaller:

```powershell
python -m pip install pyinstaller
```

Запустите сборку:

```powershell
python -m PyInstaller --clean --noconfirm Pygram.spec
```

Готовый исполняемый файл появится в:

```text
dist/Pygram.exe
```

├── requirements.txt        # Основные зависимости
└── requirements-dev.txt    # Зависимости разработки

## 📁 Структура общей сетевой папки

```text
\\SHARE\Pygram\
├── .logins/       # Хеши логинов
├── .keys/         # Публичные ключи
├── .auth/         # Данные аутентификации
├── .identities/   # Зашифрованные приватные ключи
├── .admins/       # Административный список и root trust
├── .meta/         # Метаданные чатов
├── message/       # Зашифрованные сообщения
├── files/         # Вложения
└── .status/       # Статусы, прочтения и реакции
```

## 🧪 Тестирование

В проекте используется pytest.

Тестами покрываются:

- Криптографические операции.
- Идентификация и аутентификация.
- Проверка цепочки доверия.
- Ограничение попыток входа.
- Управление административными правами.
- Логика чатов и сообщений.
- Работа с общей папкой.
- Атомарная запись и обработка ошибок.

Запуск полного набора тестов:

```powershell
python -m pytest tests/ -v
```
