# Pygram
0) Философия проекта

Что это: децентрализованный мессенджер на файловой шаре (SMB). Без сервера. Все данные — в сетевой папке. Клиент — PySide6 на Windows.

Ключевые принципы:
- Мобильность: любой ПК с доступом к шаре → вход по логину/паролю.
- Максимальная защита: логины, пароли, ключи, сообщения — не видны в открытом виде в шаре.
- Простота: один пользователь = одна пара RSA-ключей. Без forward secrecy, без ratchet (пока).
- Честность: админы могут читать всё (by design). Пользователи уведомлены.

Компромиссы (осознанные):
- Приватный ключ в шаре, зашифрован Argon2id+AES-GCM. Утечка шары → возможен офлайн-брутфорс (медленный, но возможный).
- DPAPI не используется (мобильность важнее привязки к ПК).
- Нет forward secrecy — компрометация приватника = чтение всей истории.
- Метаданные чатов зашифрованы (названия, участники).

2) СТРУКТУРА ШАРЫ (МАКСИМАЛЬНАЯ ЗАЩИТА)

\\SHARE\ 
├── .logins/                 ← <sha256(login)> (FP, created_at)
├── .keys/                   ← <fp16>.pub.pem (Публичный ключ)
├── .auth/                   ← <fp16>.auth (Argon2id хеш пароля)
├── .identities/             ← <fp16>.enc (Приватный ключ: Argon2id+AES-GCM)
├── .admins/list.json        ← Список админов (RSA-PSS подписи, is_super, can_read_all_chats, can_manage_admins)
├── .meta/
│   ├── <chat_id>.json       ← Минимум (ID, type, created_at)
│   ├── <chat_id>.enc        ← Участники (DM JSON) / Мета групп (шифр, member_permissions)
│   └── <chat_id>.keys.json  ← Обертки group_key (для групп)
├── message/<chat_id>/       ← <ts>_<sender_fp16>_<uuid>.bin (AES-GCM+RSA)
├── files/<chat_id>/         ← Вложения (картинки, файлы)
└── .status/                 ← Статусы (онлайн, печатает, прочтено, реакции, удаленные)
    ├── <fp16>.json
    ├── read/<chat_id>_<fp16>.json
    ├── reactions/<chat_id>_<msg_id>.json
    └── deleted/<chat_id>.json

Форматы chat_id:
- DM: dm_<fp16_a>__<fp16_b>
- Группа: grp_<uuid4>
- Избранное: fav_<fp16_owner>
- Админ-чат: admin_chat

Локально (%USERPROFILE%\.pygram\):
- .session_<fp16>            ← Активная сессия (TTL, boot_time)
- pygram.db                  ← SQLite кэш (сообщения, черновики, users_map)
- logs/pygram.log

НИКОГДА не хранится в открытом виде:
- Пароли (только Argon2id).
- Приватные ключи (только Argon2id+AES-GCM).
- Логины в шаре (только sha256).
- AES-ключи (только RSA-обертки).
- group_key (только обертки).
