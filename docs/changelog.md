- fix(sync): функция sync_messages_to_db теперь удаляет сообщения из локальной БД, если их файлы были удалены с шары. Это гарантирует, что история пропадает у всех участников.
- fix(status): убран вызов mkdir после rmtree при удалении истории (исправлена ошибка WinError 183 на SMB).

PYGRAM BETA 0.2.1
- fix(notifications): исправлен критический баг, из-за которого уведомления не приходили для аккаунтов, у которых не открыт чат. Ранее `sync_messages_to_db` вызывалась только для активного чата, из-за чего новые сообщения в других чатах не попадали в локальную БД, и `get_unread_count()` возвращал 0.
- feat(chat_list): добавлен фоновый поток `SyncAllWorker`, который каждые 3 секунды (по таймеру из `MainWindow`) синхронизирует ВСЕ чаты пользователя с локальной БД. Уведомления теперь работают корректно в фоне.
- fix(main_window): исправлен баг `AttributeError: 'MainWindow' object has no attribute '_tick'`. Метод `_tick` ошибочно был объявлен как вложенная функция внутри `__init__`. Вынесен на уровень класса.
- fix(chat_list): при переключении аккаунтов (метод `set_user`) теперь сбрасывается словарь `_last_unread` и `current_open_chat_id`. Это исправляет баг, когда при смене пользователя уведомления не срабатывали из-за "залипших" счетчиков от предыдущего аккаунта.
- fix(sync): в `chat_list` синхронизация вызывается с `prune_missing=False`, чтобы параллельные процессы (два открытых окна) не удаляли сообщения друг друга из общей SQLite-базы. В `chat_view` (для открытого чата) осталось `prune_missing=True`.
- fix(local_db): в SQLite добавлен `PRAGMA busy_timeout=5000` и retry-логика при `OperationalError: database is locked`. Это решает проблемы конкурентной записи, когда два окна Pygram пишут в одну БД `~/.pygram/pygram.db`.
- fix(message): удалена дублирующаяся (старая) реализация `sync_messages_to_db`, которая перезаписывала новую функцию с параметром `prune_missing`.
- fix(settings_view): исправлен баг, когда надпись "Цвета интерфейса" отображалась при выбранной «Основной» теме. Разделитель и заголовок перенесены внутрь виджета `colors_widget`, который скрывается.
- fix(settings_view): при сохранении «Основной» темы цвета в локальной БД принудительно сбрасываются на дефолтные значения (`#4a90e2`, `#e2a04a` и т.д.).
- fix(chat_view): метод `load_chat` теперь жестко применяет дефолтные цвета к делегату, если в настройках выбрана «Основная» тема, игнорируя возможные кастомные значения в БД.
- fix(main_window): при смене темы на «Основную» делегат сообщений принудительно перерисовывается через `dataChanged.emit()`. Это исправляет баг, когда после смены кастомной темы на основную цвета бабблов сообщений оставались прежними.
- feat(emoji_picker): список доступных эмодзи значительно расширен (до ~600+ штук). Добавлены новые категории: животные, природа, еда, транспорт, активности, предметы и символы. Сгруппированы по категориям с комментариями.
- fix(build): из `Pygram.spec` удалён несуществующий модуль `plyer.platforms.win.libs.win_gui`, из-за которого PyInstaller выдавал ERROR при сборке.
- build: пересобран Pygram.exe. Теперь заголовок уведомлений Windows корректно отображается как "Pygram" (вместо "Python" в dev-режиме), так как Windows берет имя из `sys.executable` собранного .exe.
